# 艾飛樂創作工作區

這是艾飛樂的內部創作資料庫，用來集中整理尚未公開的簡報、社群企劃、視覺素材與 AI 產圖紀錄。

## 資料夾用途

- `presentations/`：品牌介紹、提案、作品集與活動簡報。
- `social-media/`：社群策略、月曆、貼文腳本、文案與成效紀錄。
- `image-generation/`：AI 產圖提示詞、參考圖、生成圖片與可用版本。
- `brand-assets/`：Logo、字體、色彩、角色設定與其他品牌素材。
- `references/`：靈感收集、競品觀察與研究資料。
- `templates/`：可重複使用的簡報、貼文與產圖提示詞範本。

## 使用方式

每個新專案可在對應資料夾下建立一個以日期或主題命名的子資料夾，例如：

`presentations/2026-brand-introduction/`

請將來源檔、輸出版本和簡短說明一起保存，方便日後修改與重複使用。

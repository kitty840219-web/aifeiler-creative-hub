# 艾飛樂創作工作區

這是艾飛樂的內部創作資料庫，用來集中整理尚未公開的簡報、社群企劃、視覺素材與 AI 產圖紀錄。

## 資料夾用途

- `簡報/`：品牌介紹、提案、作品集與活動簡報。
- `社群企劃/`：社群策略、月曆、貼文腳本、文案與成效紀錄。
- `AI產圖/`：AI 產圖提示詞、參考圖、生成圖片與可用版本。
- `品牌素材/`：Logo、字體、色彩、角色設定與其他品牌素材。
- `參考資料/`：靈感收集、競品觀察與研究資料。
- `範本/`：可重複使用的簡報、貼文與產圖提示詞範本。
- `工作進度/`：每次工作的修改紀錄、完成內容與下一步。

## 使用方式

每個新專案可在對應資料夾下建立一個以日期或主題命名的子資料夾，例如：

`簡報/2026-品牌介紹/`

每次新任務請以「日期－中文主題」建立子資料夾，例如 `社群企劃/2026-10-23-秋季貼文/`。

請將來源檔、輸出版本、參考資料與簡短說明一起保存，方便日後修改與重複使用。
